# 오류고등학교 수강신청 시뮬레이터

2025·2026학년도 입학생을 하나의 화면에서 선택하는 통합 사이트입니다.
기존 GitHub Pages의 루트 `index.html`을 그대로 사용합니다. 별도 서버나 빌드가 필요하지 않습니다.

## 파일 구조

- `index.html`, `styles.css`: 입학년도 선택 화면과 공통 시뮬레이터 화면
- `app.js`: 연도 전환, 과목 선택·취소, 화면 갱신
- `engine.js`: 공통 학점 계산·선택 검증·저장용 데이터 생성
- `export.js`: 입학년도 표시가 포함된 결과 이미지 저장
- `data/2025.js`, `data/2026.js`: 연도별 전체 과목, 폐강 여부, 선택 조건, 1학년 기본 학점

각 연도의 과목 선택과 학생 입력은 현재 탭 메모리에서만 분리해서 보관합니다.
입학년도를 바꿔도 서로 섞이지 않으며, 새로고침하거나 탭을 닫으면 초기화됩니다.
학생 정보와 선택 결과는 외부로 전송하지 않습니다.
이미지 저장용 html2canvas는 기존과 동일한 cdnjs 1.4.1을 사용합니다.

## 데이터 수정

폐강은 과목의 `closed` 값을 바꿉니다. 과목을 목록에서 지우지 않습니다.
`name`, `type`(일·진·융), `credits`, `domain`은 해당 입학년도의 데이터에서 변경합니다.
`id`는 한 입학년도 내에서 유일해야 하며, 같은 과목이 여러 학기에 제공되면 중복 선택 방지용 `key`는 같게 유지합니다.
그룹 조건은 `fixed`(필수), `count`(정해진 개수), `combinations`(학점별 허용 조합)로 관리합니다.

새 입학년도는 데이터 파일을 추가하고 `app.js`에서 import 및 `admissionData` 등록을 추가합니다.
공통 화면·계산·저장 코드는 연도마다 복사할 필요가 없습니다.

## 학점 산정 범위

기존 두 사이트의 산정값을 유지합니다.

- 국어·수학·영어: 1학년 각 8학점, 총 24학점 포함. 합계 81학점 이하.
- 제2외국어·정보·교양: 1학년 정보 또는 한문 4학점 포함. 합계 16학점 이상.
- 저장 이미지의 사회·과학: 기존과 같이 2·3학년 합계만 표시. 1학년 이수 학점은 원본에 설정되어 있지 않아 임의로 추가하지 않았으며, 이미지에 적용 범위를 명시합니다.
- 일반·진로·융합 과목을 모두 합산하고, 폐강은 선택과 저장 이미지의 미선택 목록에서 제외합니다.

결과 이미지는 `1학년 / 2·3학년 / 합계`를 나누어 표시합니다.
1학년 학점이 미제공된 사회·과학은 `미반영`과 `2·3학년` 표기를 유지하며, 값을 임의로 추정하지 않습니다.

## 경고 안내

저장 시 국어·수학·영어 조건을 먼저, 이어 제2외국어·정보·교양 조건을 확인합니다.
조건을 위반한 영역만 굵은 빨간 테두리로 표시하고, 과목 선택·취소 때마다 현재 조건으로 다시 계산합니다.
해결된 영역의 테두리는 사라지고 다음 위반 영역으로 바뀝니다. 입학년도를 변경하면 경고 표시가 초기화됩니다.
중복 선택, 학점 초과, 저장 조건 등의 모든 알림은 확인을 눌러 닫는 브라우저 알림창을 사용합니다.

통합의 원본은 2025 사이트의 `a5b70f3df11f0e2ba5a49a55040c2c58a9cf3e4a`,
2026 사이트의 `8214214a38d655b6cc93064611264e6580aeb404`입니다.
기존 `preview.html` 및 별도 2026 사이트는 수정하지 않았습니다.
